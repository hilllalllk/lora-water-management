# Danışmana Sorulacaklar

Cevaplanınca tarih ve cevabı yanına yazın, gerekiyorsa ilgili ADR'yi güncelleyin.

| # | Soru | Neden önemli | Cevap |
|---|---|---|---|
| 1 | Proje başlığındaki "LoRaWAN" ifadesi "LoRa" olarak güncellenebilir mi? | Sistem LoRaWAN ağ sunucusu kullanmıyor ([ADR-0001](adr/0001-duz-lora.md)) | |
| 2 | E32-433T30D'nin çıkış gücü (~1 W) için okulun/laboratuvarın bir yönergesi var mı? Saha testine izin var mı? | 433 MHz bandında yasal güç sınırı çok daha düşük olabilir ([04 §4](04-donanim.md#4-yasal-uyarı-çıkış-gücü-ve-frekans)) | |
| 3 | Gerçek saha cihazı hangi arayüzle bağlanacak (RS485/Modbus RTU, 4–20 mA, röle)? | Uç düğüm adaptörü buna göre yazılacak (A8) | |
| 4 | Radyo şifrelemesi bitirme kapsamında beklenir mi? | v2 planında ([08](08-guvenlik.md)) | |
